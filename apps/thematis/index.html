Step 2

Code your data

Select a passage in the document, then give it a code.

How it works

  • Select a passage in the document to code it.
  • Pick a code, or type a new name to define one.
  • Hover a code in the picker to read its criteria.
  • Click highlighted text to see or remove its codes.
  • Click a code on the right to show only its passages.
  • Undo with Ctrl+Z (⌘Z on Mac), redo with Ctrl+Shift+Z.

Step 3

Build themes

Drag codes from the list below into themes on the right.

How it works

  • Drag a code from the list below onto a theme to add it there.
  • Drop a code on Make a new theme to start a theme. It appears at the bottom while you drag.
  • Drag a code from one theme to another, or back to this list to take it out of its theme.
  • Click × on a code to take it out of its theme.
  • Hover over a code or a theme name for its definition and criteria.
  • Undo with Ctrl+Z (⌘Z on Mac), redo with Ctrl+Shift+Z.

Themes are built, not found. Expect to merge, split and rename themes as you review the coded segments behind them.
